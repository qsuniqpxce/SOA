
Сервисы:
- Сервис товаров: Сервис хранит всю информацию о товарах (включая доступное сейчас количество)
- Сервис заказов: Обрабатывает всю связанное с заказами.
- Сервис аккаунтов пользователей и продавцов: хранят информацию о пользователях и продавцах не связанную с товарами/заказами
- Система рекомендаций: собирает данные со всех остальных сервисов и выдаёт рекомендации (например ленту товаров или похожие товары)
- Обработка платежей: когда пользователь делает заказ, хранилище заказов напрявляет запрос в систему обработки платежей и возращается *квитанцию* пользователю. Если заказ был оплачен в течение n минут, он напрявляется продавцу. Если нет, отменяется.
- API Gateway: принимает запросы от пользователей и перенаправляет в другие сервисы. Также отвечает за аутентификацию.
- Сервис уведомлений: Отправляет уведомлений (gmail/sms/...)
